# Jingyuan (Barton) Hou

I’m interested in **machine learning for real-world data, time-series forecasting, NLP, and reliable model evaluation**. I enjoy working on problems where data quality, evaluation design, and system constraints matter as much as model architecture.

## Selected Work

### [Translator](https://github.com/BartonHou/Translator)
A multilingual Transformer serving platform built with Hugging Face, FastAPI, Redis, Celery, PostgreSQL, and Docker.

Model routing · lazy loading / LRU model management · caching · async inference · authentication / quotas · Prometheus observability

### [World Signals](https://github.com/BartonHou/world_news)
A multi-source information pipeline combining deterministic filtering and ranking with an LLM semantic layer.

Google News · Reddit · YouTube · rule-based ranking · graceful degradation · scheduled static deployment
